# Ejercicio: ejecutar tareas en serie y en paralelo

Objetivo:
Comparar ejecucion secuencial vs paralela con promesas.

Instrucciones:
1. En `starter.js` hay un arreglo `tareas` con duraciones en ms.
2. Implementa `runSerie` que espera una por una.
3. Implementa `runParalelo` que ejecuta todas al mismo tiempo.
4. Imprime cuanto tarda cada modo usando `console.time`.

Ejecutar:
- `node 05-async-await/starter.js`
