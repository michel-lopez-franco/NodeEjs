# Ejercicio: sumar numeros desde la terminal

Objetivo:
Leer numeros desde `process.argv` y calcular la suma.

Instrucciones:
1. En `starter.js` lee los argumentos con `process.argv.slice(2)`.
2. Convierte cada valor a numero.
3. Si un valor no es numero, ignoralo.
4. Imprime la suma final.

Ejemplo de uso:
- `node 02-node-cli/starter.js 4 7 9`
- Salida esperada: `Suma: 20`
