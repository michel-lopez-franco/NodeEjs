# Ejercicio: crear un modulo de formato

Objetivo:
Crear el mismo modulo en CommonJS y en ES Modules.

Instrucciones:
1. En `commonjs/formatter.js`, implementa:
   - `toUpper(text)` devuelve el texto en mayusculas.
   - `prefix(text, pre)` devuelve `pre + text`.
2. En `commonjs/starter.js`, usa el modulo para imprimir un resultado.
3. Repite lo mismo en `esm/formatter.mjs` y `esm/starter.mjs`.

Ejecutar:
- `node 03-modulos/commonjs/starter.js`
- `node 03-modulos/esm/starter.mjs`
