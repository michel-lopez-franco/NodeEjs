# Ejercicio: consumir API con fetch

Objetivo:
Hacer una peticion HTTP y transformar el resultado.

Instrucciones:
1. En `starter.js`, haz un fetch a `https://jsonplaceholder.typicode.com/users`.
2. Convierte la respuesta a JSON.
3. Imprime un array con los nombres de usuario.
4. Maneja errores con `try/catch`.

Nota:
- Si no tienes internet, levanta el servidor del tema `07-http-server` y usa `http://localhost:3000/users`.

Ejecutar:
- `node 06-fetch/starter.js`
