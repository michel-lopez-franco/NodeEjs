# Ejercicio: resumen de compra

Objetivo:
Crear un resumen de una lista de productos usando funciones y arrays.

Instrucciones:
1. En `starter.js` hay un arreglo `items` con objetos `{ nombre, precio }`.
2. Calcula el subtotal con `reduce`.
3. Si el subtotal es mayor o igual a 100, aplica 10% de descuento.
4. Devuelve un objeto `resumen` con `subtotal`, `descuento`, `total` y `nombres`.
5. `nombres` debe ser un array con los nombres en mayusculas.

Ejecutar:
- `node 01-js-fundamentos/starter.js`
